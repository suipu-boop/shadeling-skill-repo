# 典籍整理体例

一句话：整理典籍不是抄书，是把原文拆成可检索、可对照、可积累的最小单位——条文卡。

## 条文卡六字段

每条值得记的条文做一张卡：

1. **编号**：书名缩写+条号（如「伤·31」），永久不变，引用全靠它
2. **原文**：逐字照录，不改一个字；异文在字段 3 处理
3. **校注**：各版本文字差异、难字音义、前人注家的关键分歧（注明注家）
4. **今译**：用自己的话翻成现代汉语——翻不顺的地方就是没读懂的地方
5. **按语**：你的理解、与他条的关联、临床印证；留日期，观点会长
6. **出处**：版本+卷次+篇名

## 版本留痕铁律

- 底本选定的理由写下来（ completeness/校勘质量/易得性 ）
- 引用任何条文注明「据某本」；不同版本文字不同处，正文从底本，差异记校注
- 不泥古也不轻改：无坚证不改字，有坚证必出校

## 类编按主题，不按篇章

- 原书篇章是作者的逻辑；你的类编是自己的逻辑（如按病机/按方证/按治法）
- 同一条文可入多个主题（卡片制的好处：一卡多链）
- 主题树随积累调整——早期主题设宽些，挤了再细分

## 积累纪律

- 每次读只做三五张精卡，不做百张废卡
- 卡与卡之间主动连线：方证互见、彼此发明、互相矛盾——连线时按语最出东西
- 定期回读旧卡按语：当年懂错的地方，正是进步的刻度

## 自查

1. 这张卡脱离原书还能独立读懂吗？
2. 今译是自己翻的，还是抄的参考书？
3. 编号体系能撑住整本书吗？（半途换编号 = 灾难）
