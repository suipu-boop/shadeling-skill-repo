# 数据叙事

数据叙事 = 把「我分析了一堆」变成「**你应该做 X，因为 Y**」。受众不是来看图表的，是来做决定的——你的工作是把决定变容易。

## 结构：结论先行 + 三段式

- **第一句就是结论**：「退货率三个月涨了 40%，主因是新供应商的尺码标注问题」——不是「本月我们分析了退货数据……」。分析过程放附录，结论放第一行。
- **三段式**：
  1. **背景**（基线是什么、怎么变的）
  2. **冲突**（问题或机会在哪——用数据钉死它）
  3. **解决**（建议动作 + 预期效果 + 下一步）

每段一个要点？不，**三段各承担一个职能**，细节按受众裁剪。

## 三支柱

| 支柱 | 职能 | 纪律 |
|---|---|---|
| 数据 | 证据 | 宁缺毋滥——3 个关键数字 > 30 个背景数字 |
| 叙事 | 意义 | 每个数字回答「所以呢」 |
| 视觉 | 清晰 | 一图一观点，标题写观点（「转化率翻倍」而非「转化率图」） |

## 图表选型速查

- **趋势** → 折线；**对比** → 柱状；**构成** → 堆叠/占比（少用饼图——超过 3 块就读不准）；**关系** → 散点；**漏斗** → 漏斗图/横向条形。
- 标题写**结论**不是描述：「移动端转化率是桌面端一半」>「各端转化率对比图」。
- 强调手段：给关键系列上色、其余灰色——眼睛会跟着颜色走。

## 受众裁剪

- **对高管**：结论 + 3 个证据 + 1 个请求（资源/拍板）——两分钟读完。
- **对同行**：可以上方法与细节，但结论仍先行。
- 术语匹配受众词汇：对业务方说「老客户流失」，不说「churn rate of cohort 3」。
- **以行动收尾**：每份叙事必须落在「接下来做什么、谁做、什么时候」——没有行动项的分析是消遣。

## 收尾清单

结论在第一行 / 三段式齐 / 每图一个观点且标题即结论 / 图表类型匹配数据形态 / 术语贴合受众 / 以行动项收尾。
