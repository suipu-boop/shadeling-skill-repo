# 视觉设计系统

界面的「看起来专业」来自三个系统的一致性：**字号、间距、颜色**。每个都是一组少量可数的选择，不是随手拍。

## 字号：模块化阶梯

用比例定一套字号阶（如 1.25 倍率），全界面只用阶上值：

```
xs 12 / sm 14 / base 16 / lg 18 / xl 20 / 2xl 24 / 3xl 30 / 4xl 36 / 5xl 48
```

行高配对：**标题 1.1-1.3**（紧凑有力）、**正文 1.5-1.7**（长文可读）、**UI 标签 1.2-1.4**。字号阶梯数越少越好——6 级能解决的事不要 10 级。

## 间距：8 点网格

间距只用 8 的倍数（4/8/12/16/24/32/48/64），纪律带来的对齐感是「丑界面」与「专业界面」最大的可见差异。原则：

- 相关元素间距**小**、无关区块间距**大**（亲疏关系用间距表达）
- 组件内 4/8，组件间 16/24，区块间 32/48
- 别手写 17px、23px——出现即设计系统的破口

## 颜色：语义令牌三层

```
原始层（brand-500、gray-900）      ← 色值本体
   ↑
语义层（text-primary、surface-elevated、color-error）  ← 用途
   ↑
组件层（button-bg、card-border）    ← 具体组件
```

- 代码里**只引用语义层以上**——「把主色从蓝换紫」改一处原始层，全站生效。
- 语义色四件套：success / warning / error / info，配中性灰阶 50-900。
- 明暗主题 = 语义层映射两套：`text-primary` 在亮色指 gray-900、暗色指 gray-50——组件代码零改动。

## 动效三原则（交互的补充系统）

1. **动效为传达服务**：反馈（确认操作生效）、定向（元素从哪来到哪去）、聚焦（引导注意）——装饰性动效是负资产。
2. **时长节拍**：微反馈 100-150ms、小切换 200-300ms、弹层/页面 300-500ms，超过 500ms 用户开始烦躁。
3. **缓出优先**：进场的元素用 ease-out（减速进入），离场用 ease-in；尊重系统「减弱动态效果」设置。

## 收尾清单

字号阶梯 ≤9 级 / 间距全是 8 点系 / 颜色只引语义层 / 明暗主题语义映射 / 动效有传达目的且尊重系统偏好。
