# 财务建模

财务模型 = 把业务的假设**变成可推演的数字**。核心不是预测准（没人预测得准），是假设清晰、情景齐全、能回答「如果 X 不成立会怎样」。

## 收入：同群组建模（不是拍增长率）

按获客月份分组（cohort），每组追踪：当月新客 × 逐月留存率 × ARPU，叠加增购——

```
MRR = Σ（各群组人数 × 对应留存率 × ARPU）
```

输入五件：月新增、分月留存、ARPU、定价假设、增购率。**留存率是模型的灵魂**——线性外推增长容易，诚实的留存曲线难拍。

## 成本：四分类

1. **COGS**（随客户量走）：云资源、支付通道费、随量第三方服务。
2. **S&M**（获客机器）：CAC、市场投放、销售薪酬。
3. **R&D**（产品机器）：工程薪酬、PM、设计、工具。
4. **G&A**（地板）：行政、法务财务 HR、场地保险。

人力规划拇指：早期 SaaS 工程占 40-50%、销售市场 25-35%、G&A 10-15%；单人全成本 = 基本工资 × 1.3-1.4（社保福利场地设备）。

## 现金流：模型的终点是「还能活多久」

月度推演：期初现金 + 收入 + 融资 − 支出 = 期末现金；**Runway = 期末现金 ÷ 月燃烧**——模型的第一产出物就是它，以及「最晚什么时候必须启动下一轮融资」的日期。

## 三情景框架（每版模型必备）

| 情景 | 假设 |
|---|---|
| 保守 P10 | 获客慢、定价低、流失高、周期长 |
| 基准 P50 | 当前趋势延续 |
| 乐观 P90 | 转化提升、扩张顺利 |

纪律：**决策看保守情景**（融资额按 P10 的 Runway 反推）、叙事用基准、乐观只用来识别上限——用乐观情景做预算的公司死于第一朵乌云。

## 收尾清单

同群组建模非增长率外推 / 留存假设有数据支撑 / 成本四分类 / Runway 与融资启动日期明确 / 三情景齐全 / 决策用 P10。
