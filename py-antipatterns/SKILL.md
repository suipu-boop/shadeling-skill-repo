# Python 反模式清单

收工前过一遍，每条「坏 → 改」。评审、重构、排诡异 bug 都适用。

## 基础设施

**重试散落各处**——每个函数自带超时/重试 → 收进装饰器或客户端包装，一处定义。
**双重重试**——应用层重试、底层客户端又重试 → 只在一层重试，并搞清基础设施自带的容错行为。
**配置硬编码**——连接串、密钥写进代码 → 环境变量 + 类型化配置对象（如 pydantic-settings）。

## 架构

**内部类型裸奔**——把 ORM 模型直接当 API 返回值 → 加一层 DTO/响应模型转换。
**IO 和业务逻辑搅在一起**——函数里既查库又算折扣 → 仓储模式：数据访问分离，业务逻辑写成纯函数（入参是数据，易测）。

## 错误处理

**裸吞异常**——`except Exception: pass` 把 bug 永久藏起来 → 捕获具体异常，记录后重抛或转义。
**批量操作一错全断**——循环里一项抛错整个批次作废 → 同时收集成功与失败（BatchResult 模式），返回两本账。
**入口不校验**——脏数据冲到深层才炸 → 在边界处校验（模式校验或显式检查），错误信息带上下文。

## 资源

**资源不关**——`open()` 之后不保证关闭 → 上下文管理器（`with`）包死。
**异步里写阻塞**——`time.sleep`、同步 HTTP 卡死整个事件循环 → 换原生异步库（`asyncio.sleep`、异步客户端）。

## 类型

**公共函数无注解**——`def process(data):` → 所有公开函数标出入参与返回类型。
**集合无参数**——`-> list` → `-> list[User]`，写清装的是什么。

## 测试

**只测开心路径**——只验证成功分支 → 错误分支与边界一条不落：非法邮箱、重复创建、越界值。
**万物皆 Mock**——把被测对象的所有依赖都 mock 掉，测试在验证 mock 自己 → 只 mock 边界（网络/时钟/文件），逻辑走真实现。

## 收工清单

无散落重试 / 无硬编码密钥 / 无裸吞异常 / 批量错误分账 / 入口已校验 / 资源走 with / 异步无阻塞 / 公共函数全注解 / 集合带参数 / 错误路径有测试。

## 常见修法速查

| 坏味道 | 一句话修法 |
|---|---|
| 散落重试 | 收进装饰器 |
| 硬编码配置 | 环境变量 + 类型化配置 |
| ORM 裸奔 | DTO 转换层 |
| IO 混逻辑 | 仓储模式 + 纯函数 |
| 一错全断 | 成功/失败分账返回 |
| 不关资源 | 上下文管理器 |
| 异步阻塞 | 异步原生库 |
| 只测成功 | 补错误与边界用例 |
