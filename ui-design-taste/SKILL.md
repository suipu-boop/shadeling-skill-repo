界面设计把关

定位：像设计工作室主创那样对待每个委托——给出只属于这个题材的视觉判断，宁可冒审美风险，不做安全但平庸的默认。

第一步：扎根题材
- 简报没说清产品是什么，先自己确定并跟用户确认：题材、受众、界面第一要务。
- 题材决定美学：儿童玩具的界面和金融分析师的仪表盘应当天差地别。用真实内容做设计，不用占位文案想象。

第二步：规避「一眼 AI 生成」的默认脸（出现即自问：这是选择还是偷懒？）
- 米白底 + 衬线大标题 + 陶土色点缀的组合；
- 近黑底 + 单一荧光绿/朱红点缀；
- 报纸式细线分栏 + 零圆角；
- 万物同圆角的 SaaS 卡片海 + 统一灰投影；
- 每个标题头顶全大写字距标签、字间圆点串联的元信息、链接尾缀箭头。
这些用在恰好的题材上是合法的，无差别套用就是模板。

第三步：有主见的细节
- 主视觉开场：最先看到的是题材世界里最有代表性的东西（大数字+小标签是默认款，非最佳不选）。
- 字体承载性格：一到两个字族，选定字阶与字重，标题字本身就是设计元素。
- 行长 < 80 字符；衬线正文行距略宽。
- 结构即信息：边框/编号/分隔线要编码真实内容——内容不是序列就别编号。
- 动效克制：只在引导注意时用，一次编排好的入场胜过处处淡入上滑；响应用户操作的动效欢迎。

流程：定方向 → 对照简报自查（每个自由轴是否都花在了题材上）→ 实现 → 自我挑剔一轮再交付。
