# 指标看板

看板的目标是**驱动决策**，不是展示数据。三个纪律：少而准、有上下文、口径统一。

## 三层看板体系

| 层 | 内容 | 更新 | 受众 |
|---|---|---|---|
| 战略层 | 长期目标 4-6 个头牌 KPI | 月/季 | 决策层 |
| 战术层 | 部门目标与进度 | 周/月 | 管理者 |
| 操作层 | 日常运营指标 | 实时/日 | 一线团队 |

结构自上而下：**总览 1 屏（4-6 个 KPI + 趋势 + 异常告警）→ 部门视图 → 明细下钻**——任何指标从总览两次点击内可追到明细。

## KPI 选取纪律

- **每屏 5-7 个封顶**——超过就是没想清什么重要。
- **虚荣指标出局**：只涨不跌、无法据此行动的数字（累计注册量）换成可行动指标（周活跃、转化漏斗）。
- SMART 校验：每个 KPI 有清晰定义、可量化、有目标值、对齐业务目标、有明确统计周期。
- **口径写死并展示**：计算公式直接放在指标卡上（tooltip/数据字典）——「看板和财务对不上数」八成是口径分歧（年费摊月方式不同），单一公式 + 明示是唯一解药。

## 可视化规范

- **红 = 坏、绿 = 好，全站一致**——颜色语义漂移的看板没法扫一眼读。
- 数字配**上下文**：环比/同比、目标线、趋势箭头——孤立数字没有含义（1 万是涨是跌？）。
- 柱状图 y 轴从 0 起（截断轴 = 视觉谎言）；不用 3D 图表（透视扭曲读数）；留白即排版（塞满 = 没人看）。
- 更新频率匹配决策节奏：操作层实时、战略层别做实时（白白引人盯盘）。

## 排障速查

- **看板数 ≠ 财务数**：对口径（年费摊月、退款回冲、时区边界），公式上墙。
- **没人看**：KPI 太多或不可行动——砍到 5 个真能驱动决策的。
- **指标互相矛盾**：两个团队各自定义同名指标——口径治理（见数据质量技能的合同思路）。

## 收尾清单

三层结构齐 / 每屏 5-7 个 / 虚荣指标清除 / 口径公式上墙 / 颜色语义全站一致 / 下钻两跳可达 / 更新频率对齐决策节奏。
