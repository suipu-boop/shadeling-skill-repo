# 回测纪律

回测的第一敌人不是数据量，是**偏差**——一个漏防的偏差可以让垃圾策略看起来印钞。五偏差逐一设防是底线纪律。

## 五大偏差与解法

| 偏差 | 本质 | 解法 |
|---|---|---|
| 前视偏差 | 用了当时不可能知道的信息 | **时点数据**（point-in-time）：每笔决策只许用当时已公开数据 |
| 幸存者偏差 | 只测活下来的标的 | 纳入退市/摘牌标的——已死名单才是完整名单 |
| 过拟合 | 参数拟合历史噪音 | 样本外验证 + 限参数个数 |
| 选择偏差 | 试十个策略挑最好的报 | **预注册**：先定评估标准再开测，记录全部尝试 |
| 交易成本 | 滑点/手续费/冲击归零 | 真实成本模型进回测——无成本回测无意义 |

## 数据三段切分

```
训练段（开发与优化策略）
   ↓ 冻结
验证段（选参数，绝不回头改策略结构）
   ↓ 冻结
测试段（只跑一次，最终成绩单）
```

纪律：**测试段动过一次就作废**（信息已泄漏，换新测试段或换数据窗）——「在测试集上调参」是最常见的自欺。

## 滚动前推分析（walk-forward）

滑动窗口：窗口 1 训练 → 窗口 1 测试 → 前移 → 窗口 2 训练 → 测试……把所有测试窗结果拼起来 = **策略在多市场状态下的真实轨迹**。单次 train/test 只是一个市场状态的抽样，滚动前推才能回答「换一段行情还灵不灵」。

## 不确定性度量

- 点估计之外给**蒙特卡洛区间**（打乱交易顺序/重采样收益序列看分布）——同一策略的年化可能是 5%~20% 而非一个数。
- 容量意识：资金规模改变市场冲击——小资金回测的收益在大资金上打折，规模敏感性要测。
