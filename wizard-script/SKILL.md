# 向导脚本

有一类活儿 AI 干不了（要登你的账号、点你的浏览器、填你的密码），但 AI 可以把「怎么干」写得明明白白。**向导脚本**就是一个陪着人一步步走的 bash 脚本：打开该开的网页、说清楚点哪里抄什么、把抄来的值放该放的地方、每步确认、随时显示还剩几步。

## 什么时候值得写向导

- 配置第三方服务控制台（DNS、OAuth 回调、密钥面板）——只有人能点。
- 一次性迁移（把项目从旧状态搬到新状态）——步骤多但不会重跑。
- 安装中需要「人肉获取」的凭据——AI 拿不到，人复制得来。

纯自动可跑的活儿别写向导——直接写脚本跑掉。

## 七要素

1. **开门见山**：开头一段话说清全程几步、要准备什么（账号、密码管理器）。
2. **每步一个动作**：「打开 X → 点 Y」，一次只让人做一件事。
3. **抄什么给什么**：原样给出要复制的字符串，说清粘贴到哪。
4. **即时落盘**：抄到就写进目标（.env、密钥文件），不攒到最后——中断了前面不白走。
5. **处处确认**：关键动作前后都停下来问「看到 ✓ 了吗」，人点头才走下一步。
6. **进度显示**：每步开头标「第 3/7 步」，人随时知道还剩多少。
7. **可中断续走**：重跑脚本时检测已完成的步骤并跳过——别让人从头再来。

## 脚本骨架

```bash
#!/usr/bin/env bash
set -euo pipefail
echo "=== 共 4 步：配置 DNS（2 分钟）==="
read -rp "准备好了按回车继续..."

# 第 1/4 步：动作 + 说明 + 落盘 + 确认
echo "--- 第 1/4 步：打开控制台"
echo "复制这段：example-value"
read -rp "已粘贴并保存？(y/N) " ok
[[ $ok == y ]] || exit 1
```

## 红线

- 向导里**不出现**任何自动可跑的命令——要么脚本自己跑，要么明确说「这步必须你来做」。
- 抄写的内容**回显确认**再落盘（人容易抄漏字符）。
- 中断续走逻辑必须真的测过——假续走比没有更气人。
