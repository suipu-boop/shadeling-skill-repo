# 无障碍设计

无障碍不是合规成本——键盘用户、读屏用户、色弱用户、暂时受伤的用户（绑着鼠标手）都是它服务的人。核心思路：**语义结构先行，辅助技术自然就能读**。

## 四条支柱

**1. 语义结构优先**
原生标签（按钮/链接/标题/列表）自带无障碍语义，比后补 ARIA 属性可靠——「能用原生就别加 ARIA」。标题层级不跳级（h1→h2→h3），表单控件配 label，图标按钮给可读名称。

**2. 键盘先行**
所有交互不摸鼠标也能完成。焦点顺序 = 视觉顺序；**焦点样式不禁用**（看不见焦点 = 键盘用户迷路），样式可以美化不能移除；弹层要圈焦点（focus trap），关闭后焦点归还触发点。

**3. 感知冗余**
- 非文本内容全部有文本替代（图片 alt、图标按钮 aria-label）。
- 信息不只靠颜色传达（错误同时有文字/图标——色弱用户看不出「红字」）。
- 对比度达标：正文 ≥4.5:1，大字 ≥3:1（设计时用对比度工具验，不靠目测）。
- 200% 缩放不破版。

**4. 尊重系统偏好**
- `prefers-reduced-motion`：用户关动效就别动（视动症用户的刚需）。
- `prefers-contrast` / `prefers-color-scheme`：跟随系统。

## 动态内容

异步更新（加载结果、通知）用 live region 播报，读屏用户才能「听见」页面变化；加载态给文字（「正在加载」）不只是转圈图。

## 验证路径

1. **自动扫描**（axe 类工具）扫代码级违规——低成本全覆盖。
2. **纯键盘走查**：拔鼠标走完核心流程。
3. **读屏抽测**：开 VoiceOver/TalkBack 过关键页。
4. **真人测试**：有条件就纳入残障用户——工具测不出的体验问题只有真人能暴露。

## 收尾清单

原生语义优先 / 全流程键盘可达 / 焦点可见不破不丢 / 对比度数值达标 / 信息不只靠颜色 / 动效偏好被尊重 / 动态内容有播报。
